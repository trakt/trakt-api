# Limted Access

Some endpoints are documented for visibility, but access is currently limited and may not be available to all API consumers.

Endpoints marked with **🫣 Limited Access** may require specific client access or prior approval. Your application may receive an authorization or permission error even when the endpoint appears in the API reference and the request syntax is correct.
