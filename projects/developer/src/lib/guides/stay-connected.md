# 📨 Stay Connected

API discussions and bug reports should be posted on GitHub in [trakt/trakt-api](https://github.com/trakt/trakt-api).

At minimum, we recommend watching `Discussions` on the trakt-api repository, since that’s where we’ll post API announcements, including changes, new endpoints, deprecations, and other developer updates.

Here are some direct links to help:

* Issues / support: <https://github.com/trakt/trakt-api/issues>
* Discussions and announcements: <https://github.com/trakt/trakt-api/discussions>
* API repository you can ⭐️: <https://github.com/trakt/trakt-api>
